# English Phrasebook Helper

Crie um aplicativo chamado English Easy.

O aplicativo será uma ferramenta pessoal para ajudar o usuário a aprender frases em inglês.

Crie uma interface moderna, limpa e simples, funcionando bem no computador e no celular.

Na página inicial coloque:

- Título: English Easy

- Subtítulo: "Como eu falo isso em inglês?"

- Um campo grande para escrever uma frase

- Um botão chamado "Traduzir"

- Uma área chamada "Resultado"

Por enquanto, não conecte nenhuma API ou serviço externo.

Não crie login, pagamento ou cadastro.

Quero apenas a interface inicial funcionando.
